# Como publicar no GitHub

1. Crie um repositório público `Portfolio`, sem adicionar README inicial.
2. Extraia o ZIP. Abra a pasta `Portfolio_AWS_Completo`.
3. No repositório vazio, escolha `uploading an existing file`.
4. Arraste **o conteúdo** da pasta: `README.md`, `.gitignore`, `COMO_PUBLICAR.md` e a pasta `projetos`.
5. Confirme que os caminhos aparecem como `projetos/01-servidor-web-ec2/README.md`, e não com uma pasta extra na frente.
6. Clique em `Commit changes`.
7. Abra o README principal e clique em cada projeto.
8. Revise o conteúdo de cada laboratório antes de marcar como concluído.

**Atenção:** o upload de pastas pelo navegador pode depender do navegador. Se não funcionar, use GitHub Desktop ou Git local.
